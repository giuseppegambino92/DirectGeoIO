# DirectGeoIO benchmark — NVIDIA GeForce RTX 5090 + AMD Ryzen 9 9950X3D 16-Core Processor (32 hardware threads)

End-to-end: GRIB2 file on disk → contiguous float32 values in host, unified or GPU device memory. Best of N runs; files are in the OS page cache (warm). Speed-up is relative to single-thread ecCodes.

> Measured 2026-11-19 on an otherwise idle Ubuntu 25.04 workstation (kernel 6.14, NVIDIA open driver 580.196.07,
> CUDA 12.9, sm_120 build) with ecCodes 2.50.0 (PyPI `eccodeslib` build, pthreads + AEC).
> **Storage path: pinned-host staging.** The `nvidia_fs` module is not loaded on this machine, so true GPUDirect
> Storage is unavailable (`gdscheck`: NVMe P2PDMA unsupported); libcufile's compat mode measured slower than
> DirectGeoIO's own double-buffered staging (42 vs 26 ms for 532 MB) and is therefore not used.
> The CUDA rows end with the tensor in **GPU device memory**; the CPU rows end in host memory (feeding a GPU from
> them would add a host→device copy that is not counted here).
